# 游戏缩略图目录

此目录用于存放游戏卡片的缩略图。

## 所需图片

请将以下游戏的截图(推荐尺寸: 1280x720 或 16:9 比例)放置在此目录:

1. `wigglypaint.jpg` - WigglyPaint 游戏截图
2. `ovo-unblocked.jpg` - OVO Unblocked 游戏截图
3. `pixilart.jpg` - Make Pixel Art Online 游戏截图
4. `different-strokes.jpg` - Different Strokes 游戏截图
5. `drawaria.jpg` - Drawaria.online 游戏截图
6. `sandspiel.jpg` - Sandspiel 游戏截图
7. `webgl-fluid.jpg` - WebGL Fluid Simulation 游戏截图
8. `jspaint.jpg` - JS Paint 游戏截图

## 图片规格建议

- **格式**: JPG 或 PNG
- **尺寸**: 1280x720px (16:9 比例)
- **文件大小**: < 200KB (优化后)
- **内容**: 游戏实际运行界面截图

## 降级方案

如果图片不存在或加载失败,系统会自动显示 emoji 图标作为降级方案。
